# Кузница 3D-Игрушек

Информационный сайт проекта № 107789 программы «Студенческий стартап».

## Публикация

1. Разместите в корне репозитория `index.html`, `style.css`, `script.js`, `favicon.svg` и папку `assets/images` из полного ZIP-архива сайта.
2. Для GitHub Free переведите репозиторий в Public (Settings → General → Change repository visibility).
3. В Settings → Pages выберите **Deploy from a branch** → **main** → **/(root)** → Save.

Ожидаемый адрес: https://ArslanMuginov.github.io/StS_KUZNICHA3D/

## Соответствие техническому заданию

На главной странице размещаются логотипы Фонда содействия инновациям и Платформы университетского технологического предпринимательства, а также текст поддержки из технического задания договора № 1732ГССС27/107789 от 06.11.2025.

Фотографии игрушек извлечены из отчёта второго этапа, предоставленного владельцем проекта.

Сайт информационный: нет корзины и передачи персональных данных; перед публикацией необходимо проверить корректность отображения официальной символики.
