# Кузница 3D-Игрушек

Информационный сайт проекта № 107789 программы «Студенческий стартап».

## Готово

Исходный код и реальные фотографии изделий уже загружены в ветку `main`:

- `index.html` — страница с блоками «О проекте», «Наши игрушки», «Как создаём», «Поддержка».
- `style.css` — адаптивное оформление для компьютера и телефона.
- `script.js` — мобильное меню, увеличение фото и обработка ошибок загрузки логотипов.
- `assets/images/` — фотографии трёх изделий из заключительного отчёта.
- `favicon.svg` — значок проекта.

Текст государственной поддержки на главной странице воспроизводит пункт 3.2 технического задания к договору № 1732ГССС27/107789 от 06.11.2025.

## Как включить GitHub Pages

1. Репозиторий создан в статусе Private. Для публикации через GitHub Pages на обычном бесплатном аккаунте откройте `Settings → General → Danger Zone → Change repository visibility → Public` (это сделает весь код публичным).
2. Перейдите в `Settings → Pages → Build and deployment`.
3. Выберите `Deploy from a branch`, ветка `main`, папка `/(root)`, затем `Save`.
4. После успешной публикации ожидаемый адрес: https://ArslanMuginov.github.io/StS_KUZNICHA3D/

## Обязательная проверка перед отчётностью

- Обе внешние картинки с официальной символикой должны **действительно отображаться** на публичном сайте на телефоне и компьютере. Ссылки в текущей версии ведут на изображение Фонда у партнёра (университетский сайт) и на SVG-логотип с официального сайта Платформы. Надёжнее сохранить подтверждённые официальные версии локально в репозитории.
- Сверить размеры, контраст и отступы логотипов с бренд-материалами.
- Проверить работу меню, галереи и мобильной верстки.
- Сайт пока не содержит формы отправки заявок и не обрабатывает личные данные.
- Если проекту нужен полноценный коммерческий интернет-магазин, следует выбрать подходящий для этого хостинг вместо GitHub Pages.
